# Ramanujan's conjecture for powers of 11 (Atkin 1967): research notes and plan

Target: `24m ≡ 1 (mod 11^k) ⇒ 11^k ∣ p(m)`. The repo already proves the 5^k and 7^k cases (`Pow5Final`, `Pow7Final`).

All numerical claims below were checked by script with exact integer arithmetic, mostly to q^1500–q^3000. The scripts are not in the repo; they ran in a session scratchpad.

## Why the 5/7 method does not carry over
- X₀(11) has genus 1. Functions on Γ₀(11) with poles only at cusps are not generated by η-quotients; the only η-quotients are powers of `z = q⁵E(q¹¹)¹²/E(q)¹²`.
- So the "dissection algebra" of the 5/7 proofs does not close.
- No elementary (pure q-series) proof is in the literature. Atkin 1967, Gordon 1983 and Paule–Radu 2018/19 all use modular functions on X₀(11).
- Paule–Radu's algorithmic proof needs a degree-55 modular equation (1531 terms, coefficients up to 313 digits) and 550 base relations (1.6 GB). That is too large to formalize as written.

## Compact data (Gordon/Atkin style, all verified)
- **Atkin basis.** `g₂, g₃` with `g₄ = g₂² − g₃` and `g₆ = g₂g₄`. All multiplication follows from two relations:
  - `R1: g₂g₃ = g₂² − g₃ + 11z`
  - `R2: g₃² = g₂³ − g₂g₃ − z`
- **Curve relation.** `g₂⁵ = z(1 + 13g₂ + 34g₂²) + 121z²`. This is the elliptic curve 11a1.
  - Its root with `g₂ = q + O(q²)` is unique (Hensel), so `g₂` can be *defined* as that root.
  - Then `g₃ = (g₂² + 11z)/(1 + g₂)`.
- **Degree-11 modular equation** for `φ = q⁵E(q¹²¹)/E(q)`: `φ¹¹ = Σ_{j=1}^{11} (−1)^{j+1} e_j(q¹¹) φ^{11−j}`, with
  - `e₁ = 121g₂ + 2662g₃ + 14641g₄ + 161051z`
  - `e₂ = −11g₂ + 968g₃ + 11979g₄ + 161051z`
  - `e₃ = 242g₃ + 5324g₄ + 73205z`
  - `e₄ = 22g₃ + 1452g₄ + 14641z`
  - `e₅ = 242g₄ − 1331z`, `e₆ = 22g₄ − 1331z`
  - `e₇ = −121z`, `e₈ = 121z`, `e₉ = 55z`, `e₁₀ = 11z`, `e₁₁ = z`
  - Checked to q³⁰⁴².
- **Recurrence.** `U₁₁(φ^λF)` satisfies an order-11 recurrence in λ. The identity `z(q)z(q¹¹) = φ¹²` gives the shift `C^λ_{5a+i,ν} = C^{λ+12a}_{i,ν+5a}`.
- **Seeds.** `U₁₁(φ^λ J_i) = Σ_ν C^λ_{i,ν} J_ν` for i = 0..4 and 11 consecutive λ.
  - Window λ ∈ [−22,−12]: 210 coefficients, 1216 digits; needs Laurent series. Example: `U(φ⁻²²g₂) = 11⁸z⁻¹g₄`.
  - Window λ ∈ [0,10]: 3031 coefficients; stays in ℤ⟦q⟧.
- **11-adic bound** (Gordon): `v₁₁(C^λ_{i,ν}) ≥ ⌊(11ν − i − 5λ + δ(i, ν mod 5))/10⌋`, with `δ = [[-1,8,7,6,15],[0,9,8,2,11],[1,10,4,3,12],[2,6,5,4,13],[3,7,6,5,9]]`.
  - The tight value of δ(2,3) is 3. Mestrige's restatement prints 13, which is a typo, but that entry is never used.
  - The bound is inductive under the recurrence. The step is a periodic finite check (λ mod 2, ν mod 10) with no violations.
- **Final induction.**
  - `L_r = Σ_{ν≥1} a_{r,ν}J_ν` with `v₁₁(a_{r,ν}) ≥ r + ⌊(ν−1)/2⌋`, where `J_{5a+i} = z^a(1, g₂, g₃, g₄, g₆)[i]`.
  - Base case: `L₁ = 11g₂ + 242g₃ + 1331g₄ + 14641z`.
  - This gives `11^r ∣ p(11^r n + μ_r)`, with `μ_{2β−1} = (1 + 13·11^{2β−1})/24` and `μ_{2β} = (1 + 23·11^{2β})/24`.

## Plan
1. **Conditional theorem.** "modular equation + R2 + seeds ⇒ 11^k ∣ p(m)". It is pure power-series algebra plus finite `decide`/`omega` tables. Estimate: 2.5–4k lines. These inputs must be stated as explicit hypotheses, never as axioms.
2. **Prove the inputs.** Two routes:
   - **(β) Elementary.** The 11-dissection of E (verified): `E(q) = E(q¹²¹)[θ₄/θ₂ − qθ₂/θ₁ − q²θ₅/θ₃ + q⁵ + q⁷θ₃/θ₄ − q¹⁵θ₁/θ₅]`, with `θ_a = (Q^a, Q^{11−a}, Q¹¹; Q¹¹)_∞` and `Q = q¹¹`. The first characteristic-polynomial coefficients of `E/(q⁵E(q¹²¹))` follow from 11-dissections of E, E², E³ (Jacobi) and E⁴. The risk is that the known cubic theta relations span only 89 of the 121 dimensions needed, so quartic identities (Winquist?) are required.
   - **(α) Analytic.** A Sturm/valence principle on Γ₀(11), Γ₀(22) and Γ₀(121); about 5–15k lines.
