# Ramanujan's Lost Notebook p. 206: φ(e^{−7π√7}) (Rebák, Theorem 4.1)

    φ(e^{−7π√7}) = 7^{−3/4} φ(e^{−π√7}) {1 + (cos(π/7)/(2cos²(2π/7)))^{2/7}
                                          + (cos(2π/7)/(2cos²(3π/7)))^{2/7}
                                          + (cos(3π/7)/(2cos²(π/7)))^{2/7}}

The statement is `RamanujanTau.Septic.Page206Evaluation` (`Septic/Page206.lean`).

**Status: PROVED unconditionally.** The theorem is `RamanujanTau.Septic.page206_unconditional : Page206Evaluation`
(`Septic/Page206Final.lean`). It depends only on `[propext, Classical.choice, Quot.sound]`; there is no `sorry`,
no `native_decide` and no new axiom. The audit is `scripts/audit/septic_page206.lean`.

The proof uses neither Son's modular equations nor the class invariant G₇. Instead it uses three lattice
identities: the 4-dimensional quaternion one and two 8-dimensional ones. It also uses an elimination certificate
and crude numerical enclosures at x₀ = e^{−π/(7√7)}. Son's general q-series identities (Entry 1.1(iii) and the
sextic relation) remain **unproved** as ℤ⟦q⟧ identities. They are stated as `SepticSonCore` (`Septic/Son.lean`)
and used only in the alternative conditional route `page206_of_sonCore`.
(`docs/SEPTIC_ENTRY_1_1.md` predates this and still says "not proved"; it was left untouched per the
no-edit rule.)

## Notation

The variable is x = Rebák's q^{1/7}. The 7-dissection of φ(x) = Σ x^{k²} is

    a = Σ_{k≡0} x^{k²} = φ(x⁴⁹),  b = Σ_{k≡±1} = x f(x³⁵,x⁶³),  c = Σ_{k≡±2} = x⁴ f(x²¹,x⁷⁷),  d = Σ_{k≡±3} = x⁹ f(x⁷,x⁹¹),

with one sign class each, so that φ = a + 2b + 2c + 2d. Also Φ = φ(x⁷).
In Lean these are `T 0..T 3` and `ramF 7 7`, with u = 2b/a, v = 2c/a, w = 2d/a, p = uvw = 8bcd/a³, R = Φ⁴/a⁴.

## Key reformulation of Entry 1.1(iv)/(v)

Solving u⁷ = α²p/β, v⁷ = β²p/γ, w⁷ = γ²p/α gives **α = u³v, β = v³w, γ = w³u**. So (iv)+(v) say exactly that
u³v, v³w, w³u are the roots of r(ξ) = ξ³ + 2(1+3p−R)ξ² + p²(p+4)ξ − p⁴, i.e. two symmetric-function identities:

* (A) u³v + v³w + w³u = 2R − 6p − 2  ⇔  **Φ⁴ = a⁴ + 24abcd + 8(b³c + c³d + d³b)**
* (B) u²v³ + v²w³ + w²u³ = p² + 4p  ⇔  **a(b²c³ + c²d³ + d²b³) = a³bcd + 2(bcd)²**

Note: Rebák's Lemma 3.4(i) is printed as u³v+v³w+w³u = 2R − 3p − 1. That fails numerically; the correct
right-hand side is 2R − 6p − 2.

## The proof chain

1. **Lemma 2.1** `rebak_lemma_2_1`: φ(e^{−π/√n}) = n^{1/4} φ(e^{−π√n}), from Mathlib's
   `jacobiTheta₂_functional_equation` (`Septic/Transform.lean`). At n = 343 this gives φ(x₀) = 7^{3/4} φ(e^{−7π√7})
   with x₀ = e^{−π/(7√7)} (`phi_x0`). At n = 7 it gives R = 7 (`R_eq_seven`).
2. **Real transfer** (`Septic/RealTransfer.lean`): `evHom x : convSub x →+* ℝ` is evaluation on absolutely
   convergent ℤ⟦q⟧ series (Cauchy product). `hasSum_fibre` regroups bilateral sums. Results: `evR_ramF_mm`
   (φ(q^m) ↦ phiR(x^m)) and `evR_T` (T r ↦ Σ_{n∈ℤ} x^{(7n+r)²}).
3. **(A), the quaternion identity** (`Septic/Quaternion.lean`, `quaternion_identity`). Left multiplication by the
   Lipschitz quaternion 2+i+j+k (norm 7) is a bijection ℤ⁴ → L = {k : Mᵀk ≡ 0 (7)} with |Mn|² = 7|n|².
   L mod 7 is the isotropic plane k₂ ≡ 3k₀+2k₁, k₃ ≡ 2k₀+4k₁. Splitting L into its 49 cosets gives the identity.
   This is pure counting. Proved for all q, as a ℤ⟦q⟧ identity.
4. **Numerics at x₀** (`Septic/Bounds.lean`): 0.83 ≤ x₀ ≤ 0.8555, then two-term-plus-geometric-tail enclosures of
   a, b, c, d. These give 16c³d < a⁴, 16d³b < a⁴, c³ > d²b (`ineq_s2`, `ineq_s3`, `ineq_s23`), i.e. v³w < 1,
   w³u < 1, v³w > w³u.
5. **The cubic** (`Septic/Cubic.lean`): r(ξ) = ξ³ − 6ξ² + 5ξ − 1 has roots 1/(4cos²(kπ/7)), via Mathlib's
   Chebyshev U₆ (`U6_eq`, `U6_cos`). Also the order facts 1/(4cos²(3π/7)) > 1 > 1/(4cos²(2π/7)) > 1/(4cos²(π/7)).
6. **Algebra** (`Septic/Page206Proof.lean`, `septic_algebra_of_p`). Given p = 1, (A), (B), R = 7 and the
   enclosures:
   - e₁ = 6, e₂ = 5, e₃ = 1, so u³v, v³w, w³u are the roots of r;
   - the enclosures identify u³v = 1/(4cos²(3π/7)), v³w = 1/(4cos²(2π/7)) and w³u = 1/(4cos²(π/7));
   - u⁷ = (u³v)²/(v³w) and its cyclic versions give the three cosine terms.

   This replaces Rebák's Lemmas 3.2–3.8. The bound u³v > 1 is not needed: it follows from e₁ = 6.
7. **p = 1 and (B) at x₀.** Two routes:
   * **conditional route** `page206_of_sonCore : SepticSonCore → Page206Evaluation`. Here
     `SepticSonCore := SonSextic ∧ SonEntryIII` (`Septic/Son.lean`). (iii) with R = 7 reads
     (1−p)((1−p)² + 35) = 0, so p = 1. This replaces G₇ = 2^{1/4}.
   * **unconditional route** `page206_unconditional` (`Septic/Page206Final.lean`). It uses two **8-dimensional
     lattice identities** (`Septic/Octo1.lean`, `Octo2.lean`, generated by `scripts/septic/gen_octo2.py`).
     - For a Lagrangian W ⊂ F₇⁸ (form Σxᵢ², hyperbolic over F₇), L_W/√7 is unimodular of rank 8. We exhibit
       M ∈ M₈(ℤ) with MᵀM = 7I and Mℤ⁸ = L_W, so Φ⁸ = Σ_{v∈W} Π T_{vᵢ} = P_W(a,b,c,d). The proof is the same as
       for the quaternion identity, with 2401 cosets.
     - For the two W's chosen, P_W − Q₄² ≠ 0 (where Q₄ is the quartic in (A)), so these are genuinely new
       degree-8 relations.
     - At x₀ (R = 7) they give three equations g₁ = g₂ = g₃ = 0 in B = b/a, C = c/a, D = d/a. The Singular
       `lift` certificates in `Septic/Cert.lean` (`scripts/septic/gen_cert.py`) give two facts:
       - `cert_f5`: f₅(8BCD)² = Σ hᵢgᵢ, with f₅(t) = (t−1)(t²−2t+36)(7t²+22t−36). The enclosure
         8BCD < 1.18 then forces p = 1. The only competing real root is t = (−11+√373)/7 ≈ 1.1876.
       - `cert_Bp`: (B) lies in (g₁, g₂, g₃, 8BCD−1).

## Why lattices, and what does not work

* Among a, b, c, d there is **no** polynomial relation of degree < 6. The degree-6 part of the ideal has
  dimension 10; (B) is one of these relations. (iii), with (A) substituted, lies in the ideal of the sextic
  relations (`scripts/septic/check_son_core.py`, sympy Groebner).
* In dimension 6, x₁²+…+x₆² has Witt index 2 over F₇ (−1 is a non-square), so there is no 6-dimensional analogue
  of the quaternion trick.
* In dimension 8 the random Lagrangians fall into 4 pattern types, and they span only a 2-dimensional space of
  degree-8 relations. That is not enough to generate (B) in ℤ⟦q⟧. At the special point, however, the finitely
  many solutions plus the numeric enclosures suffice.
