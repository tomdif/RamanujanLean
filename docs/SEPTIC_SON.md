## The idea: rational isometries with denominator 7

The obstruction recorded earlier was that there is no Lagrangian in F₇⁶, so there is no 6-dimensional
"Φ⁶ = P_W" identity. The way around it is not to compare with Φ at all, but to compare two *different*
class-lattices with each other:

* Let M ∈ Mₙ(ℤ) with MᵀM = 49·I, so g = M/7 ∈ Oₙ(ℚ).
* Let U ⊂ F₇ⁿ satisfy rowspace(M mod 7) ⊆ U ⊆ ker(M mod 7).
* Then g maps L_U = {k ∈ ℤⁿ : k mod 7 ∈ U} isometrically onto L_U', where U' is the image subspace.
* So Σ_{L_U} q^{|k|²} = Σ_{L_U'} q^{|k|²}. Splitting each side by k mod 7 gives
  **P_U(a,b,c,d) = P_U'(a,b,c,d)** with P_U = Σ_{u∈U} Π_i T_{u_i}.

These identities are generally non-trivial. In Lean each one is pure counting, in the same style as
`Quaternion.lean`:

1. L_U is parametrised by z ∈ ℤⁿ through its pivot basis.
2. An explicit equivalence ℤⁿ ≃ U × ℤⁿ (proved with `omega`) splits L_U into cosets.
3. The isometry becomes an integer unimodular matrix V, with |B_U'Vz|² = |B_U z|² checked by `ring`.
4. `cnt_congr`, `cnt_fin_prod` and `cnt_mul` (all from `Quaternion.lean`) finish the argument.
