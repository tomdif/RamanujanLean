# Exact Jensen (higher-order Turán) thresholds for p(n) at degrees 6 and 7

**Result.** Let `J^{d,n}(X) = Σ_{j=0}^{d} C(d,j) p(n+j) X^j`. Then

* `J^{6,n}` is hyperbolic (all roots real) for every `n ≥ 610`, and `J^{6,609}` is not. So **N(6) = 610**.
* `J^{7,n}` is hyperbolic for every `n ≥ 908`, and `J^{7,907}` is not. So **N(7) = 908**.

**Convention.** This is the Larson–Wagner convention: `N(d)` is the least `N` with `J^{d,n}` hyperbolic for all
`n ≥ N`. In it, `N(2) = 25` (Nicolas; DeSalvo–Pak), `N(3) = 94` (Chen–Jia–Wang; Larson–Wagner), and
`N(4) = 206`, `N(5) = 381` (Larson–Wagner, Res. Number Theory 2019, Thm 1.1). `docs/FRONTIER_FINDINGS.md` §3 lists
the *last failing* `n` instead (24, 93, 205, 380, 609, 907). That is the same data shifted by one. The pipeline
below independently reproduces `N(2..5)` = 25, 94, 206, 381 exactly.

**Literature.** Larson–Wagner state (§3, Remark) that their Hankel-determinant method does not reach `d = 6`:
"A code for d = 6 with s = 16 did not finish within 36 hours". GORZ (PNAS 2019) prove only that the
polynomials are eventually hyperbolic. Larson–Wagner's general bound `(3d)^{24d}(50d)^{3d²}` is astronomically
large. I searched (Nov 2026) and found no proof of `N(6)` or `N(7)` for `p(n)`. (The values `N_PL(6) = 102` and
`N_PL(7) = 136` in the literature are for *plane* partitions.)

## The tail argument (formalized; originally level 3)

**Input.** Let `U_m = π√((2/3)(m − 1/24))` and `M(m) = K e^{U_m}(U_m−1)/(2U_m³)`. Then
`|p(m) − M(m)| ≤ K e^{U_m/2}` for `m ≥ 2` (Lean: `Rademacher.p_sub_main_le`). Hence `p(m) = M(m)(1+ε_m)` with
`|ε_m| ≤ 2U³e^{−U/2}/(U−1)`.

**Normalization.** Fix `n` and set `f(s) = log M(n+s)` for real `s`. Let `A = f'(0)`, `δ² = −f''(0)/2`,
`φ(s) = f(s) − f(0) − As`, and `w_j = p(n+j)e^{−Aj}/M(n) = e^{φ(j)}(1+ε_{n+j})`. The Newton forward-difference
identity `Σ_j C(d,j)(Z−1)^j w_j = Σ_k C(d,k) Δ^k w(0) (Z−1)^k Z^{d−k}` gives

```
J^{d,n}(e^{−A}(δx − 1)) = M(n) δ^d G(x),    G(x) = Σ_k C(d,k) γ_k x^{d−k} (δx − 1)^k,    γ_k = Δ^k w(0)/δ^k.
```

As `n → ∞` we have `γ_k → Y_k(0,−2,0,…) = (d/dy)^k e^{−y²}|₀`, and `G` tends to the Hermite-type polynomial
`T_6 = x⁶ − 30x⁴ + 180x² − 120` (for d = 7, `T_7 = x⁷ − 42x⁵ + 420x³ − 840x`).

**Enclosures.** Three facts give interval enclosures of the `γ_k`:

* **B-spline (Peano kernel) form.** `Δ^k g(0) = ∫_0^k M_k(t) g^{(k)}(t) dt`, where `M_k ≥ 0` has mass 1, mean
  `k/2` and variance `k/12`. Taylor-expanding about `k/2` (the linear term integrates to zero) gives
  `γ_k ∈ [e^φ Y_k(Φ)](k/2) + (k/24)δ² · hull_{[0,k]}[e^φ Y_{k+2}(Φ)]`.
* **Faà di Bruno.** `Y_k` is the complete Bell polynomial and `Φ_m = φ^{(m)}/δ^m`.
* **Exact derivatives.** With `h = 1/U`, we have `f^{(m)} = R_m(h)U^{1−2m}`, where the `R_m` are exact rational
  functions (`derivs.py`; e.g. `R_2 = a²(6h³−12h²+6h−1)/(4(h−1)²)`, `a = 2π²/3`). Hence
  `Φ_m = R_m(h_s)/Q^{m/2} · ρ^{1−2m} · U_0^{1−m/2}`, where `Q = −R_2(h_0)/2` and `ρ = U_s/U_0 ∈ [1, √(1+ad/U_0²)]`.
  Also `Φ_1 = s f''(θ)/δ` and `Φ_0 = s² f''(θ)/2`. All of these are evaluated in `arb` ball arithmetic
  over a box of `U_0`.

The term from `ε` contributes at most `2^k ε_max/δ^k ≤ 2^k · 2U³e^{−U/2}/(U−1) · U^{3k/2}/Q^{k/2}`. This bound
decreases in `U` for `U > 3d + 10`.

**Certificate.** Cover `U_0 ∈ [U_start, ∞)` by geometric boxes, the last one infinite: `h_0 ∈ [0, 1/U_lo]`,
with `U_0^{1−m/2} ∈ [0, U_lo^{1−m/2}]`. On each box, check in ball arithmetic that `G` has the sign pattern of
`T_d` at `d+1` rational points. The points are fixed Hermite midpoints, or the root-midpoints of the box's
midpoint polynomial in `adaptive` mode. A strict sign alternation gives `d` distinct real roots of `G`, hence
of `J^{d,n}`.

**Sanity check.** At `n = 3000` the enclosures contain the exact values of `G` computed from `p(n+j)`. For
example, `G(0) = −101.11113…` lies in `[−101.1111 ± 0.0076]`.

**Thresholds reached** (`tail_cert.log`): `J^{d,n}` is hyperbolic for every `n ≥ n₀(d)`:

| d | U_start | n₀(d) | boxes | infinite box from U = | Larson–Wagner's n₀ |
|---|---|---|---|---|---|
| 2 | 36 | 198 | 20 | 88 | — |
| 3 | 50 | 380 | 20 | 123 | 344 |
| 4 | 65 | 643 | 20 | 160 | 572 |
| 5 | 80 | 973 | 20 | 196 | 2316 |
| **6** | 90 | **1232** | 40 | 561 | (method did not finish) |
| **7** | 105 | **1676** | 60 | 1815 | — |

Below `U ≈ 89` (d = 6) the bottleneck is not the Hermite approximation but the crude Lehmer error `K e^{U/2}`,
because `δ^{−6} ~ U⁹` multiplies it. A sharper explicit tail (the `k = 2` Rademacher term) would lower `n₀`. That
is not needed: the finite range is already cheap.

**Finite range** (`finite_check.py`, about 1 min):

* Exact root counts (sympy `count_roots`: integer Sturm/Vincent, no floating point) for `1 ≤ n < n₀(d)`,
  `d = 2..7`, give last failures 24, 93, 205, 380, 609, 907.
* For d = 6 and 7 the script writes rational sign-alternation certificates for `N(d) ≤ n < n₀(d)`, verified
  exactly in integer arithmetic. The Lean kernel re-checks them.
* It also writes the Laguerre-violation points at `n = N(d) − 1`.

## How the formalized tail works (differences from `tail_cert.py`)

The Lean certificate uses the same normalization `G(x) = Σ_k C(d,k) γ_k x^{d−k}(δx−1)^k`, `γ_k = Δ^k w(0)/δ^k`,
but encloses `γ_k` by a **one-sided Taylor expansion at 0** of `g = e^φ` to order `K = d + 3`:
`Δ^k g(0) = Σ_{i<K} g^{(i)}(0)/i!·Δ^k[j^i](0) + Δ^k R`, with `Δ^k[j^i](0) = 0` for `i < k` (kernel-checked) and
`|R_j| ≤ sup|g^{(K)}|·j^K/K!`. At `s = 0` one has `Φ₀ = Φ₁ = 0`, `Φ₂ = −2` exactly, and
`Φ_m(0) = Q_m(u₀,ω₀)·t₀^{m−2}/c₂^{m/2}`. The derivatives `g^{(i)}` come from the Leibniz chain
`g_{k+1} = Σ C(k,i) g_{k−i} φ_{i+1}`, so no Bell polynomials or Peano kernels are needed. Over `s ∈ [0, d]`, the
values `Φ₀, Φ₁` come from Taylor bounds on `f''` and `Φ_m` from the `ρ`-scaled closed form. The Lehmer error
uses `e^{−x} ≤ 1/Σ_{i<60} x^i/i!` on finite boxes and `e^{−x} ≤ 60!/x^{60}` on the infinite box.
`scripts/jensen/proto.py` is the ball-arithmetic prototype of exactly this scheme, and
`scripts/jensen/gen_tail.py` chooses the boxes (requiring margin > 2). Each of the 16 (d=6) and 25 (d=7) boxes is
then re-checked by the kernel.

## Remaining gaps

None for d = 6, 7: both thresholds are unconditional, axiom-clean Lean theorems. The same machinery
(`box_sound` is generic in `d` given the Newton identity) would give Lean proofs of `N(2..5)` and of `d = 8, …`.
For each degree that needs the Newton identity at that `d`, boxes from `gen_tail.py`, a finite table to `n₀ + d`,
and a Laguerre point. This has not been done. For `d ≥ 8` the kernel cost of the d = 7 box check (15 min) is the
main obstacle.
